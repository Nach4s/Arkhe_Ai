# 🤖 Arkhe AI - Telegram Bot для анализа стартап-презентаций

**Arkhe AI** — это интеллектуальный Telegram-бот, который проводит экспертный анализ стартап-презентаций по ключевым инвестиционным критериям, используя **Groq AI** (LLaMA 3.3 70B) — самую быструю и бесплатную AI-платформу.

## 🎯 Возможности

Бот анализирует презентации по 10 критериям:

1. **Решение реальной проблемы** - актуальность и болезненность проблемы
2. **Уникальность и конкуренты** - конкурентные преимущества
3. **Целевая аудитория** - чёткость определения клиентов
4. **Объём рынка** - TAM, SAM, SOM
5. **MVP / Прототип** - стадия разработки продукта
6. **Монетизация** - бизнес-модель
7. **Финансовая модель** - прогнозы и юнит-экономика
8. **Основные риски** - ключевые риски проекта
9. **Сравнение с известными стартапами** - аналогии с Airbnb, Uber, Notion и др.
10. **Оценка по методу Бёркуса** - оценка в долларах по 5 параметрам
11. **Режим дебатов (/debates)** - жёсткие инвестиционные дебаты с AI-инвестором

## 🧠 Функция: Режим дебатов (/debates)

### 📌 Описание

Команда `/debates` запускает режим инвестиционных дебатов — формат жёсткого, критического диалога по стартап-презентации.

В этом режиме Arkhe AI выступает не помощником, а скептически настроенным венчурным инвестором, задача которого — поставить под сомнение ключевые тезисы, вскрыть слабые места и проверить мышление фаундера под давлением.

Это имитация закрытого обсуждения в инвестиционном комитете, а не публичного питча.

### 🧑‍⚖️ Роль AI

AI действует строго в роли:

**Старший партнёр венчурного фонда / член инвестиционного комитета** с опытом анализа 1000+ стартапов на стадиях pre-seed, seed, Series A.

**AI обязан:**
- сомневаться
- давить на допущения
- вскрывать логические дыры
- задавать неудобные вопросы

**AI НЕ должен:**
- быть мягким ради комфорта
- подбадривать без фактов
- объяснять базовые вещи
- давать советы без запроса

### 🔄 Логика работы команды /debates

1. Пользователь загружает презентацию (PDF / PPTX)
2. Пользователь вводит `/debates`
3. AI:
   - изучает презентацию
   - не делает анализа и не резюмирует
   - сразу начинает дебаты
4. AI задаёт критичные, провокационные вопросы
5. Пользователь отвечает
6. AI:
   - цепляется за неточности
   - усиливает давление
   - задаёт уточняющие вопросы, если ответ размытый или уводящий

### 🎯 Принцип вопросов

Вопросы должны:
- ставить пользователя в интеллектуально неудобное положение
- проверять глубину понимания, а не заученные фразы
- симулировать разговор с инвестором, который не хочет верить на слово

### 🧨 Блоки дебатов и примеры вопросов

#### 1️⃣ Проблема — «Она правда существует?»
- Что произойдёт, если эту проблему никогда не решат?
- Кто прямо сейчас платит за её решение?
- Почему рынок до сих пор не закрыл эту боль?

#### 2️⃣ Решение — «Почему именно вы?»
- Что реально ломается, если ваш продукт исчезнет?
- Что в вашем решении сложно повторить, а не просто реализовать?
- Почему это не функция в существующем продукте?

#### 3️⃣ Клиент — «Кто реально страдает?»
- Кто платит деньги, а не просто пользуется?
- Как вы проверяли готовность платить, а не интерес?
- Кому будет по-настоящему больно, если вы закроетесь?

#### 4️⃣ Рынок — «Он действительно большой?»
- Какие допущения искусственно раздувают TAM?
- Кого вы сознательно исключили из рынка и почему?
- Что должно измениться, чтобы ваш рост стал возможен?

#### 5️⃣ Конкуренты — «Кто вас убьёт?»
- Кто уже владеет отношениями с клиентом?
- Почему крупный игрок просто не скопирует вас?
- Кого вы боитесь больше всего — и почему?

#### 6️⃣ Продукт и реализация — «Вы точно это вытянете?»
- Что оказалось сложнее, чем вы ожидали?
- Где продукт сейчас самый хрупкий?
- Что сломается первым при росте в 10 раз?

#### 7️⃣ Монетизация — «Почему деньги пойдут к вам?»
- За что клиент платит на самом деле?
- Почему цена именно такая, а не любая другая?
- Что будет с ростом, если цену увеличить вдвое?

#### 8️⃣ Финансы — «Где модель разваливается?»
- Какая метрика критична и почему?
- Какое допущение, если оно неверно, убьёт компанию?
- Где вы сами выглядите слишком оптимистично?

#### 9️⃣ Риски — «Что вы недооцениваете?»
- О каком риске вы стараетесь не говорить?
- Какой внешний фактор может уничтожить бизнес?
- Что лично вас больше всего смущает в проекте?

#### 🔟 Инвест-логика — «Почему сейчас и почему вы?»
- Почему эта компания должна существовать сейчас, а не позже?
- Почему именно ваша команда справится?
- Что произойдёт, если вы не привлечёте инвестиции?

### 🗣️ Тон общения

- Прямой
- Скептический
- Спокойный, но жёсткий
- Иногда конфронтационный
- Без эмодзи
- Без мотивационных фраз
- Без воды

Это не менторство и не обучение — это инвестиционные дебаты.

### 📤 Формат ответов AI

- 1–2 чётких вопроса за сообщение
- Короткие формулировки
- Уточняющие вопросы при уходе от ответа
- Никаких выводов, пока пользователь не попросит

### 🚫 Ограничения

- AI не подводит итоги без запроса
- AI не оценивает стартап
- AI не даёт рекомендаций без прямой просьбы
- AI не переписывает презентацию
- AI не смягчает формулировки

## 🚀 Установка и запуск

### 1. Клонируйте репозиторий или создайте структуру проекта

```bash
git clone <your-repo-url>
cd Arkhe_Ai
```

### 2. Создайте виртуальное окружение

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте переменные окружения

Создайте файл `.env` на основе `.env.example`:

```bash
copy .env.example .env  # Windows
# или
cp .env.example .env    # Linux/Mac
```

Заполните `.env` своими данными:

```env
BOT_TOKEN=your_telegram_bot_token_here
GROQ_API_KEY=your_groq_api_key_here
LOG_LEVEL=INFO
```

### 5. Запустите бота

```bash
python bot.py
```

## 💡 Использование

1. Найдите бота в Telegram по имени или ссылке
2. Отправьте команду `/start`
3. Загрузите презентацию стартапа в формате **PDF** или **PPTX**
4. Дождитесь анализа (обычно 10-30 секунд)
5. Получите подробный экспертный разбор с оценкой по методу Бёркуса

- ⚡ **Сверхбыстрые ответы** - в 10-20 раз быстрее GPT-4
- 💰 **Полностью бесплатно** - не нужно пополнять баланс
- 🧠 **Мощная модель** - LLaMA 3.3 70B от Meta
- 🔓 **Открытый доступ** - регистрация через GitHub

## 📊 Метод Бёркуса

Бот использует метод оценки стартапов Дэйва Бёркуса (Dave Berkus Method):

- **Идея и ценность**: 0-500k USD
- **Прототип**: 0-500k USD
- **Команда**: 0-500k USD
- **Стратегические партнёрства**: 0-500k USD
- **Продажи/Traction**: 0-500k USD

**Максимальная оценка**: $2,500,000

## ⚠️ Ограничения

- Поддерживаются только форматы **PDF** и **PPTX**
- Максимальный размер анализируемого текста: ~12,000 символов
- Бот работает без базы данных (stateless)
- Временные файлы автоматически удаляются после обработки
